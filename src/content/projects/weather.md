## Approach

I used browser JavaScript to capture a city, request current conditions from OpenWeather, handle the response, and render useful details into a focused interface.

## Result

The project gave me a practical foundation in asynchronous API calls, DOM updates, responsive styling, and the complete path from an idea to a working web experience.
